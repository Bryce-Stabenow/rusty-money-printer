# TL;DR - This prints money

## The Goal
I have seen a ton of really dumb and vibe-coded projects interacting with Kalshi and Polymarket in order to find arbitrage or other opportunities to make money. I respect the hustle, but this project is meant to do things differently. 

This project will be entirely hand-written. That's not because I can do it better and faster than AI--in fact it will be worse and slower--it is because I want a good reason to re-sharpen my skills and keep working on things that make me happy, not just prompt my way to the end goal.

## What It Do?
This connects, like said above, to trading markets and is responsible for printing money. That is based on arbitrage opportunities, user-defined strategies for trading, and other pathways. By default, this opens connections to both Polymarket and Kalshi and needs API connections to both.

## Running This Project
- It's Rust. Make sure that's installed
- Run it with `cargo run`
- Keep your terminal open to interact
